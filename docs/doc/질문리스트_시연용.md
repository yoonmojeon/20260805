# 문서 검색 시연 질문 리스트

아래 질문을 그대로 입력해 보세요.

## 표에서 값을 찾는 질문

선급 규칙·지침의 표에서 특정 값을 찾아옵니다.

1. 실린더 출구별 배기가스 온도가 평균에서 벗어나면 이중차단·배출밸브의 자동 작동이 요구되는가?
2. 기관실 격벽은 어느 위치의 횡격벽을 의미하는가?
3. 재화중량이 10만 톤 초과 15만 톤 이하인 선박의 안전사용하중은 몇 톤인가?
4. 어느 면도 해수에 접하지 않는 부재의 부식 두께는 몇 mm인가?
5. RD·RY·RW·RU 308L 용접재료 시험에 적용되는 강종은 무엇인가?
6. RSTH 12·22·23·24 관을 확관한 후 관 끝의 허용 바깥지름은 원래 관 바깥지름의 몇 배인가?
7. 형상이 복잡하거나 한 개의 중량이 10톤을 넘는 주강품은 제품마다 시험재가 몇 개 필요한가?
8. 적층제조 최종 재료의 제조법 승인에는 지침의 어느 장을 적용하는가?
9. ESP·EXP 부호가 있는 Oil/Bulk/Ore Carrier의 설계에는 어느 장을 적용하는가?
10. 구명정 승정구역이나 개방갑판의 임시 안전대피구역에 필요한 방화 보존성 등급은 무엇인가?

## 문서 내용을 묻는 질문

IMO 회의 문서와 선급 Rule 본문을 읽고 정리합니다.

1. LR에서 대체연료 관련 Rule/Guidance를 찾아줘.
2. DNV-CG-0264 — Autonomous and remotely operated vessels를 기준으로, Concept Qualification은 어떤 두 목적에 쓰여?
3. ABS Guide for Smart Functions for Marine Vessels and Offshore Units v8를 기준으로, ABS Smart Functions Guide가 제시하는 네 가지 목적을 정리해줘.
4. MSC 111/5 — 회기간 MASS 작업반 보고를 기준으로, mandatory MASS Code와 STCW 전면검토의 예상 일정은 언제야?
5. ABS Requirements for Autonomous and Remote Control Functions v4를 기준으로, 이 Requirements의 위험정보 기반 접근이 검증활동에 어떻게 쓰여?
6. IMO MEPC 최신 회의의 환경규제 대응 포인트를 정리해 주세요.
7. 최신 MEPC의 operational impact 항목을 한국어로 정리해줘.
8. MSC 111-WP.1 — MSC 111 본회의 보고서 초안을 기준으로 '수소 연료 잠정 안전지침은 부결됐다'라는 전제가 맞는지 검증하고, 틀리면 문서 근거로 바로잡아줘.
9. MSC 111-WP.1 및 MSC 111/12 — 대체연료·GHG 안전 결과를 기준으로 '리튬이온 배터리 작업은 계획에서 삭제됐다'라는 전제가 맞는지 검증하고, 틀리면 문서 근거로 바로잡아줘.
10. 환경규제 대응과 관련된 최신 MEPC 회의 주요 내용을 정리해줘. 제안문과 최종 결정문이 섞이면 결정 상태를 구분하고 확정 근거만 사용해줘.
