## 실제 사례 3개

### 1. HYBRID 성공과 모델 차이

- 질문: `현재 우리 선박의 CII 성적이 IMO·MEPC 관리 요구에 부합하는지 실제 수치와 규정을 함께 비교해줘.`
- 모범답안: 현재 CII 등급 E, attained 약 6.396, required 약 3.731을 IMO·MEPC 문서 요구와 비교
- 현재 Gemma 실제 답안 핵심: `Attained CII 6.396`, `Required CII 3.731`, `CII 등급 E`를 제시하고 요구치에 부합하지 않는다고 결론
- 기존 규칙+Gemma 실제 답안 핵심: MEPC 84의 선대 평균 탄소집약도만 설명하고 현재 선박 실측값은 누락
- 현재 Mistral 실제 답안: `CII 등급 C`, `Attained 0.138`, `Required 0.097`로 잘못 답함

### 2. 직전 항차 수치

- 질문: `바로 전 적재 운항에서 이동거리와 CO2 배출 실적이 어떻게 됐어?`
- 모범답안: `H2521_V20_Laden`, `5470.5 nm`, `4662.82 MT CO2`
- 현재 Gemma 실제 답안: `이전 항차(H2521_V20_Laden)... 총 이동 거리 5470.5해리... CO2 배출량 4662.82톤`
- 현재 Mistral 실제 답안: `이동 거리 2,345해리, CO2 배출량 17,500톤`으로 오답

### 3. 전 모델 공통 표 검색 실패

- 질문: `14편_2025.pdf 19쪽 표에서 AC-S·AC-SD·AC-A·AC-T 선체 구조 지지부재의 허용응력은 어느 절을 따르나?`
