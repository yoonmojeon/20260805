- 전체 715개 PDF 중 서로 다른 문서 150개를 층화 표본으로 선정했다.
- 기관별 구성: DNV 60, MEPC 40, MSC 22, KR 18, ABS 9, LR 1.
- 각 PDF마다 실제 답변 가능한 질문 1개와 원문 근거·정답 요점을 구성했다.

## 3. 주요 수정

- 271k 청크 전체 BM25를 매 질의마다 스캔하지 않고, 정상 dense 후보에 특징 명사가 없을 때만
  Chroma `where_document={"$contains": ...}` 정확일치 보강을 한 번 수행한다. 재임베딩은 하지 않았다.
- `방식조치` 같은 희소 한국어 복합명사와 질문에 병기된 영문 전문용어를 정확일치 후보로 회수한다.
- `방식조치의 요건과 예외` 최종 실답변은 연료유 탱크 제외 강재 표면 요건과 갑판·내저판 참작 예외를 첫 결론으로 제시하고, 종전의 비관련 프로펠러 부착 조항을 생성 컨텍스트에서 제외한다.
- 명시 PDF 내부에서 정의, 상대연도 수치, 비교 이유, 전체 제출 목록, 병렬 조건-수치 문단을 우선한다.
- Accurate 생성은 질문과 직접 관련된 같은 문서의 인접 청크를 추가로 사용할 수 있다.
- 목록 초안이 “다음과 같습니다”에서 끝나면 실패로 판정하고, 현재 검색 근거의 모든 원문 항목을
  LLM이 번호별로 번역한 뒤 누락 여부를 검사한다. 고정 답변 템플릿이나 gold 답은 사용하지 않는다.
- 같은 근거 문장에 `오일/수분 6 m/s`, `그리스 3 m/s`처럼 병렬 값이 있으면 한쪽 누락을 검출해 재생성한다.
- 사용자가 요구한 네 섹션과 카테고리별 bullet 수, 회의차수·문서명·조항/결의/가이드 인용 규칙을 유지한다.
- 표 검색에는 한영 별칭, 띄어쓰기 변형, 정확 행·열 교차, 후보 0건 시 정확일치 보강,
  복수 범주·충돌 값·비율·기호 답변을 추가했다.
- UI 시작 시 로컬 E5 모델을 사용하면서 외부 모델 저장소 확인을 반복하지 않도록 기본 오프라인 로딩을 적용했다.

## 4. 직접 확인한 대표 회귀

- `progressive couplings`: 강성 증가와 평균/진동 토크·주파수·온도·영구변형의 상호의존성을 답함.
- DNV-CP-0097 유형 시험 장소: 협회 실험실, 인정 독립 실험실, 검사관 입회 제조사 구내를 모두 답했으며 2차 판정 4/4로 통과함.
- DNV 비금속 호스 TA 제출 서류: 원문의 12개 항목을 1)~12)까지 모두 답함.
- 마모 시험 원주 속도: 오일/수분 6 m/s와 그리스 3 m/s를 모두 답함.
- MEPC 84-6-2 공급기반 탄소집약도: 2019년 대비 2024년 최대 10.8% 감소를 답함.
- MSC 111-19-1 administrative requirement: A.1043(27), 정보/데이터 제공·보유 의무를 답함.
- 사용자가 제시한 암모니아 개념승인 질문을 최종 Accurate 경로로 다시 생성한 결과, MSC 111의 승인·향후 개정 범위와 DNV `Fuel ready`, KR `Ammonia Ready`를 함께 인용하고 탱크·연료계통, 환기·가스검지, 위험성평가 체크 항목을 제시했다. 종전의 MSC 한 문서 반복 답변은 해소됐지만 상세 AIP 제출물 전체 목록 수준은 아니므로 기본설계 체크리스트로 해석해야 한다.

## 5. 라우팅과 남은 위험

- “KR 규정 질문이 회의 요약으로 간다”는 현상은 재현되지 않았다. 재측정 10문항은
  rule_guidance_lookup 3, fast_rag 5, structured_meeting 2로 분기됐고 회의 경로에는 실제 MEPC·MSC 질문만 갔다.
  따라서 이 항목을 고치기 위한 변경은 하지 않았다.
- 검색과 답변은 유의하게 개선됐지만 150문항 자동 2차 판정 통과율이 38%이므로 완성 상태는 아니다.
  특히 정답 PDF가 후보 풀에 없는 약 20.7%, 정답 출처가 최종 인용에 없는 약 32.7%가 남은 우선 개선 대상이다.
- 근거 없는 구체 주장 자동 판정이 15.33%이므로 UI의 “근거 확인 후 사용자 검토” 표시는 유지해야 한다.
- 실제 전문가가 UI에서 질문·답변·근거를 보고 Correct / Partial / Wrong 및 누락 사유를 기록하는
  검수 루프가 다음 단계다. 그 피드백을 문항별 예외가 아니라 실패 유형별 회귀 테스트로 추가해야 한다.
